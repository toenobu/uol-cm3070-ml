# uol-cm3070-ml

This repository handle the machine learning aspects of the system

## Features

- **Model Training**: Jupyter notebooks for Scripts and configurations for training image classification models in Amazon SageMaker
- **Model Evaluation**: Comprehensive validation code and performance metrics assessment
- **Deployment Pipeline**: Automated workflows for deploying trained models to AWS Lambda
- **Inference Logic**: Optimized code for real-time inference in serverless environments
- **Data Analysis**: Jupyter notebooks for exploratory data analysis of the CM3070 dataset
